## 2024-09-20 - Keyboard Form Submission
**Learning:** To support native keyboard form submission (e.g., pressing 'Enter'), ensure input-heavy widgets use semantic `<form onSubmit={...}>` wrappers and `<button type="submit">` rather than `<div className="form">` wrappers with `onClick` handlers on the submission button. Ensure that all internal `<button>` elements not intended to submit the form explicitly have `type="button"` to prevent unintended premature submissions. Enforce disabled states inside the `onSubmit` handler (e.g., `if (!isLocked) handleCommit()`) to prevent users from bypassing disabled `<button type="submit">` states by pressing 'Enter' in an input field.
**Action:** Always wrap input fields in semantic forms with submit buttons and explicit button types for internal actions.

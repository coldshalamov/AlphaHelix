## 2024-05-20 - Add native keyboard submission to commit widget
**Learning:** To support native keyboard form submission (e.g., pressing 'Enter'), ensure input-heavy widgets use semantic `<form onSubmit={...}>` wrappers and `<button type="submit">` rather than `<div className="form">` wrappers with `onClick` handlers on the submission button. Ensure that all internal `<button>` elements not intended to submit the form explicitly have `type="button"` to prevent unintended premature submissions. Additionally, enforce disabled states inside the `onSubmit` handler (e.g., `if (!isLocked) handleCommit()`) to prevent users from bypassing disabled `<button type="submit">` states by pressing 'Enter' in an input field.
**Action:** Always wrap forms in a `<form>` tag and use `<button type="submit">` for the submit button. Ensure all other buttons in the form have `type="button"`. Check for disabled states in the `onSubmit` handler.
